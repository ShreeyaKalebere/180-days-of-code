# Day 32: Reverse Words in a Sentence

## Problem Statement
Reverse the order of words in a sentence. Words are separated by one or more spaces; print them separated by a single space.

**Input:** one line of text.
**Output:** the words in reverse order.

### Sample Input
```

```

### Sample Output
```

```
