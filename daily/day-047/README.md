# Day 47: Find a Peak Element

## Problem Statement
A peak is an element strictly greater than its neighbours (`a[-1] = a[n] = -∞`). Find the index of any peak in O(log n). For the sample there is exactly one peak.

**Input:** `n`, then `n` integers (adjacent values differ).
**Output:** the index of a peak.

### Sample Input
```
6
1 3 5 7 4 2
```

### Sample Output
```
3
```
