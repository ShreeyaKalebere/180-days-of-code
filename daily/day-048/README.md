# Day 48: Two Sum in a Sorted Array

## Problem Statement
Given a sorted array, find two indices (0-based) whose values add up to `target` using two pointers. Print `-1 -1` if no pair exists.

**Input:** `n target`, then `n` sorted integers.
**Output:** `i j` with `i < j`.

### Sample Input
```
6 13
1 3 4 6 9 11
```

### Sample Output
