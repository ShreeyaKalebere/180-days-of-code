# Day 5: Grade Calculator

## Problem Statement
Read marks out of 100 and print the grade:
- 90 and above: `A`
- 75 to 89: `B`
- 60 to 74: `C`
- 40 to 59: `D`
- below 40: `F`

**Input:** an integer `marks`.
**Output:** a single letter.

### Sample Input
```
82
```

### Sample Output
